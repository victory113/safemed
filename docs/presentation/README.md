# Presentation deck

`../SafeMed_Final_Presentation.pptx` is generated by `build.js`, which is the
source of truth for the deck. Editing the `.pptx` directly is fine for a quick
fix before presenting, but the change will be lost the next time anyone
rebuilds — put anything you want to keep into `build.js`.

```bash
cd docs/presentation
npm install pptxgenjs
NODE_PATH="$PWD/node_modules" node build.js
```

18 slides. Speaker notes are on every slide; the live demonstration sits at
slide 12 and follows [DEMO.md](../DEMO.md) rather than the slides.

Theme colours are applied by `apply_theme.js` from Claude's pptx skill. The
build works without it — the deck simply falls back to Office's stock scheme
colours for a few placeholder defaults. Point `PPTX_SKILL` at that skill's
`scripts` directory to enable it.
